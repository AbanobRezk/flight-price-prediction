# Flight Price Prediction

Exploratory analysis and regression models to predict airline ticket prices.

## Dataset
`airlines_flights_data.csv`: 300,153 flights across 6 airlines and 6 Indian cities, with features such as airline, source and destination city, departure time, stops, class, duration and days left before departure.

## Workflow
- Data cleaning and exploratory analysis (price by airline, class, stops, departure time and days left)
- Outlier handling, label encoding and feature scaling
- Models: Linear Regression, Random Forest, XGBoost, SVR

## Results
| Model | R² |
|---|---|
| Random Forest | 98.42% |
| XGBoost | 97.45% |
| Linear Regression | 90.41% |

## Tech Stack
Python, pandas, NumPy, scikit-learn, XGBoost, Matplotlib, Seaborn
